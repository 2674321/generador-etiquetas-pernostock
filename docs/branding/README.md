# Identidad visual — PernoLabel

Recursos visuales livianos del proyecto:

- `app-icon.svg`: icono 1:1 para tarjetas, accesos directos, portfolio y documentación.
- `hero-banner.svg`: cabecera 3:1 para README, landing, dashboard o pantalla de inicio.

## Integración

```html
<img src="docs/branding/hero-banner.svg" alt="PernoLabel" class="brand-hero">
```

```css
.brand-hero { width: 100%; height: auto; border-radius: 18px; display: block; }
```

Los assets son puramente visuales y no contienen datos operativos o personales.
